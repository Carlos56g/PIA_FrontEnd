# PIA_FrontEnd  
Proyecto Final – FrontEnd Class

Este proyecto corresponde al PIA de la clase de **FrontEnd**, y está basado en un proyecto previo desarrollado para la materia de **Aprendizaje Automático**.

## 📘 Contexto del Proyecto  
El proyecto original incluía un sistema de recomendación y un análisis más profundo en temas de machine learning.  
Puedes consultar la documentación completa y la explicación técnica del sistema en el siguiente enlace:

👉 **[Documentación – Google Drive (PDF en Español)](https://drive.google.com/file/d/15nPV8xrtWlijFu4VL1BO3Rcx3DnA5cxS/view?usp=sharing)**

---

## 🎨 Cambios Realizados para la Clase de FrontEnd  
Para esta clase, se realizó una reestructuración del proyecto con los siguientes objetivos principales:

- ✔️ Reorganizar completamente la arquitectura del proyecto siguiendo **heurísticas de diseño**.  
- ✔️ Implementar **despliegue en la nube** utilizando Google Cloud Run.  
- ✔️ Modernizar y mejorar la **Interfaz de Usuario (UI)** para ofrecer una mejor experiencia.

---

## 🚀 Tecnologías Utilizadas  
- React (con Vite)
- JavaScript / HTML / CSS  
- Google Cloud Run  
- Node.js  
- API REST del sistema de recomendación
